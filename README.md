# Phần mềm Quản lý Nhân sự (LTNC)

Dự án phần mềm quản lý nhân sự trên nền tảng Desktop, áp dụng kiến trúc 3 lớp (3-Tier) chuẩn và được quản lý bằng Maven. 

## Tính năng chính
- Quản lý thông tin Nhân viên, Phòng ban và Chức vụ.
- Hỗ trợ các thao tác Thêm, Sửa, Xóa, Xem dữ liệu.
- Tích hợp tính năng xuất báo cáo danh sách ra file Excel.
- Giao diện trực quan được xây dựng bằng Java Swing.

## Công nghệ và Cấu trúc
- **Ngôn ngữ:** Java
- **Giao diện:** Java Swing
- **Cơ sở dữ liệu:** MySQL (kết nối qua JDBC)
- **Quản lý thư viện:** Maven
- **Kiến trúc:** 3-Tier (Phân tách rõ ràng giữa các thư mục `dao`, `model`, `view`)
